# 스텔라 위브 — 식으로 엮는 별빛

중1 문자의 사용과 식의 값을 다루는 12라운드 자원 배분 퍼즐입니다. 실타래를 고르고 엮으면 식의 값만큼 빛을 쓰며, 다음 주문에 쓸 식을 남겨야 합니다.

`npm test`, `npm run build`, `npm start`로 검증·독립 빌드·실행합니다. 로컬 포트는 51249입니다. Vercel은 Other, npm run build, dist를 사용합니다.

배경·실타래·버튼·메달·나방·직물 보상은 내장 image_gen으로 제작했습니다. 프롬프트는 assets/prompts.json, 수학 근거와 범위는 sources.json, assessment.json, 참고 게임과 변형은 design.json에 있습니다. 교과서 원문은 포함하지 않습니다.

기록은 브라우저 기기에 저장되며 계정 동기화는 아닙니다. 첫 방문 연습은 저장된 본 게임과 독립입니다. 학습 확인 과제의 첫 응답·힌트·재시도·설명·소요 시간을 보존하고 읽을 수 있는 노트를 저장할 수 있습니다. 게임 승리로 공식 이수를 판정하지 않습니다.
